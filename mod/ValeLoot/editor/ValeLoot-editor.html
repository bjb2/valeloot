The easy way is F8. Start the game, press F8, and ValeLoot opens this same editor in your browser with your rules, your bag and every item name already loaded — no folder to choose and no file to find. This screen is what you get when you opened the file by hand: it is the fallback for a blocked port, or for writing rules with the game shut.

Your rules live in one text file inside your game folder. ValeLoot reads that file and paints your bag from it. To edit the rules here, this page needs to see the folder they are in — SpiritVale/BepInEx/config.
